# Prompt: Full Application Kit

Copy everything below the line into ChatGPT, Claude, Gemini, or Codex.

---

Help me prepare an honest job-application kit from a job posting and my current CV/resume. Do not invent or embellish anything.

I will provide:
1. The job posting
2. My CV/resume
3. Optionally, a visual reference for my CV, a preferred output language, and confirmed practical details I want included

## Step 1: Check inputs
Confirm that you have the job posting and CV. If either is missing, ask for only the missing item. If I request a visually recreated CV but have not shared a layout reference, ask for a PDF, image, or template.

Use the posting's language unless I ask for another language.

## Step 2: Analyse first
Before drafting, produce a concise `Fit snapshot` with:
- role title, level, and must-have requirements;
- an honest match score out of 100;
- strongest evidence of fit;
- material gaps or eligibility checks marked `Verify`.

Ask one concise question only if an answer could materially change the CV or letter. Otherwise continue with visible placeholders.

## Step 3: Produce the application kit
Create these deliverables in this order:

### A. Tailored CV draft
Reorder and rephrase only my existing experience to make the most relevant evidence easy to find. Use the job posting's vocabulary only when accurate. Preserve the source structure and approximate length. If a layout reference was supplied, add brief design-preservation notes.

### B. Cover or motivation letter
Write a targeted letter using only evidence from my materials. Default to a 250–350 word cover letter unless I request a motivation letter.

### C. Recruiter-style screening report
Include:
- match score and verdict;
- requirement-by-requirement table: requirement | my evidence | Strong / Partial / Miss / Verify;
- strengths to lead with;
- gaps, missing keywords, and high-leverage improvements;
- better-fit adjacent roles if the score is below 50.

### D. Final verification list
List every placeholder, unverified fact, and claim I should review before applying.

Rules:
- Never invent skills, responsibilities, results, metrics, dates, qualifications, language levels, work authorisation, or personal details.
- Use `[add metric]` or `[to confirm]` whenever information is missing.
- Do not keyword-stuff or create claims that cannot be defended in an interview.
- Keep the tone constructive, direct, and respectful.
- Wait for my source materials before beginning.
