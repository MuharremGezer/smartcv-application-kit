# Prompt: Tailor My CV

Copy everything below the line into ChatGPT, Claude, Gemini, or Codex.

---

Help me tailor my CV/resume for a specific job while keeping every claim truthful.

I will provide:
1. The job posting
2. My current CV/resume
3. If relevant, a PDF, image, or description of my current CV design
4. My preferred output language, if different from the job posting

Before writing, confirm that you have the job posting and the CV. If I want a visually formatted CV but have only pasted text, ask for a PDF, image, or template that shows the original layout.

Then work in the job posting's language unless I specify another one.

## Deliverable

Create a tailored CV draft with these sections as supported by my source CV:
- Role-focused headline
- Professional summary
- Experience
- Education
- Skills
- Projects, certifications, or languages only when they are present in my source materials

## Tailoring method

1. Extract the role's must-have requirements, nice-to-haves, seniority, and relevant vocabulary.
2. Reorder existing experience so the most relevant, truthful evidence appears first.
3. Rewrite bullets for clarity and relevance using the job posting's terminology only where it accurately describes my experience.
4. Preserve the source CV's meaning, chronology, and level of responsibility.
5. Keep the source CV's approximate length and section hierarchy unless I ask to change them.
6. If I supplied a visual reference, describe how to preserve its layout, typography, colour, columns, and visual hierarchy. Do not replace it with a generic design.

## Output format

Return:
1. `Tailored CV draft` — the complete revised text.
2. `Changes made` — a short bullet list of reordered or rewritten items.
3. `Items to confirm` — every `[to confirm]` or `[add metric]` placeholder, with a concise question for each.
4. `Design notes` — only if I supplied a visual reference.

Rules:
- Never invent metrics, employers, projects, tools, responsibilities, qualifications, certifications, languages, or dates.
- Do not add a photo, age, nationality, marital status, work authorisation, or similar personal information unless I explicitly provide it and request its use.
- Do not keyword-stuff.
- Keep claims specific and defensible in an interview.

Wait for my materials before starting.
